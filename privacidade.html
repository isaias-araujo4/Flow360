Privacidade

Como o Flow360 trata seus dados

O Flow360 organiza documentos trabalhistas de empresas terceirizadas (folhas de pagamento, guias, kits demissionais etc.) para conferência pelo cliente contratante, em linha com a Lei Geral de Proteção de Dados (Lei nº 13.709/2018).

Quais dados usamos

  • Nome, login e cargo de quem acessa o sistema;
  • Dados cadastrais de empresas, clientes, unidades e colaboradores;
  • Os documentos enviados e o histórico de ações sobre eles.

Para que usamos

  • Conferir se a documentação obrigatória foi entregue no prazo;
  • Registrar quem enviou, aprovou ou recusou cada documento;
  • Gerar relatórios para a gestão do contrato.

Onde ficam os dados nesta versão

Esta é uma versão acadêmica. Todos os dados ficam guardados somente neste navegador (localStorage) e não são enviados para nenhum servidor.

Apagar dados deste navegador

Remove tudo o que foi salvo e volta aos dados de exemplo.
